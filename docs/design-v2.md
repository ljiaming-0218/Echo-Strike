# 时间追猎 · CHRONO HUNT · 2.0

用户明确选择“与过去的自己战斗，走位和攻击成为下一轮的威胁”。本规则替代旧版docs/plan.md中的玩法；旧文件作为历史设计保留。继续沿用Phaser、纯TypeScript核心和静态部署。

## 一局体验

六轮对抗，每轮最多12秒。手动瞄准射击3个时间锚，并击破场上所有敌对过去，出口才解锁。站进出口光环保持0.4秒撤离；最早在本轮第3秒开放撤离。失败条件是HP归零或12秒耗尽；死亡优先于同tick撤离。最后一轮撤离即胜利。

第1轮只有时间锚。成功撤离后，完整保留这一轮的实际位置、朝向、冲刺状态以及**成功提交**的射击/脉冲；复盘画出路径与历史射线。按“进入下一轮”后，此记录生成敌对自己。

每个过去循环重演自己的实际行动长度，不锁定、不追踪、不重新计算输入。保留最近3份记录，FIFO。它们只伤害现在的你，不攻击时间锚或互相攻击。真人子弹可以击破过去；过去被击破后本轮停火，但在途子弹继续存在。下一轮保留的历史会重建为完整HP，必须再次击破；击破过去并不删除原始记录。新记录不包含任何过去的攻击。

## 操作与技能

- PC：WASD/方向键移动，鼠标瞄准、按住左键射击（J为键盘开火备选）；Space冲刺，Q抹除脉冲，Esc暂停。
- 手机横屏：左摇杆移动、右摇杆瞄准并持续射击；冲刺与脉冲按钮独立。按pointerId归属，取消/失焦/竖屏会清空输入。
- 冲刺：9tick、速度720、冷却150tick，期间免伤且不能开火；同时按脉冲时冲刺优先。
- 脉冲：每轮1次，半径160、伤害24，清除附近历史子弹并伤害附近过去。历史脉冲也会在原位置造成伤害，不能盲目滥用。
- 每轮开始恢复20HP（上限100），补充技能与护盾45tick；无局中三选一、自动瞄准、怪物刷波或180秒生存目标。

## 仿真与碰撞

60Hz单一固定步，以completedTicks/roundTick为权威。世界1280×720、FIT居中；两个固定掩体同时阻挡移动和子弹。移动按小步轴向处理，冲刺不能穿墙；弹丸相对运动连续碰撞，取最早目标/掩体/场地交点。新子弹创建当步只检查发射点，之后才扣TTL。历史循环跳点同时重置前后姿态，不制造跨场扫掠。

真人100HP；枪伤12、间隔12tick、速度900；过去36HP；锚24HP。命中后0.5秒保护，免伤中的敌对弹丸仍消费。快照冻结，攻击来源仅保存ID/参数，无活对象引用。最多3个过去、每段720姿态/128事件、240在途弹丸、100视觉事件。

MENU→RUNNING→REVIEW→下一轮RUNNING，最终VICTORY或DEFEAT。手动/失焦/隐藏/竖屏/性能暂停叠加；移除某一原因不能绕过其他原因。恢复必须显式继续，不追赶后台时间。每次重开新建World，不重复挂载输入与场景监听。

## 表现

延续用户原方案的程序几何美术约束，不引入外部素材/CDN。新视觉为墨紫背景、纸白真人、珊瑚色敌对过去、金色时间锚和淡紫时钟刻度。菜单展示现在与过去相互指向；战场显示闭合倒计时与撤离条件；复盘使用真实行动数据。HUD与按钮为原生DOM，碰撞全部以纯核心坐标为准。

## 2.1：实验室表现与应用内横屏（覆盖前文旧表现限制）

用户反馈画面单调，并明确在微信/QQ内无法横屏。本次改为生成的可行走实验室地面与透明装甲角色，本地WebP共约375KiB；原碰撞位置不变，掩体、金色时间锚、传送门、命中/破碎反馈和有限残影叠加绘制。旧“仅程序几何”表现约束由本次美术改善要求更新。

使用同一个#viewport包住Canvas与DOM界面，固定1280×720的渲染缓冲以舞台本地尺寸执行FIT。Phaser自动FIT改为手动CSS居中适配，避免旋转后的getBoundingClientRect宽高被误当作逻辑父尺寸。布局按实际逻辑宽高设置data属性，兼容无需CSS Container Queries的内置浏览器。

微信/QQ不承诺系统方向锁定。竖屏页提供“横向适配并开始/继续”，整体旋转90度并交换逻辑宽高，双摇杆与鼠标坐标做同一逆变换。原生全屏/方向锁定只在按钮点击手势内请求；缺失/拒绝仍可横向游玩。恢复自动布局会重新进入竖屏暂停，不绕过hidden原因。复盘时适配后，下一轮不残留不可见暂停。visualViewport变化用于避免工具栏遮住操作。

减少特效会关闭密集历史残影、碎屑等；对象、标记和特效均维持固定容量。静态图片不额外造成战斗碰撞，新增hit事件仅供表现，不改变伤害或记录。
