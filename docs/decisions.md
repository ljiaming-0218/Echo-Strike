# 实施决策

## M0 · 2026-10-26

- 按上传计划书先完成 M0，不提前构造人物、菜单、战斗、时钟或分身空类。
- 保留 GitHub 仓库名 Echo-Strike；游戏显示名采用 ECHO RUSH / 回响特攻，不修改 origin。
- 使用本机实际可用的 Node 24.19.0 / npm 11.9.0，精确锁定 Phaser 3.90.0、TypeScript 5.9.3、Vite 7.3.7、Vitest 4.1.12，避免升级 Phaser 主版本。
- 依计划先使用程序几何背景，无生成美术、外部素材 CDN 或新增框架。
- 系统默认 npm 缓存目录不可写；采用项目 .npmrc 的相对 .npm-cache，不更改系统权限。
- Phaser 单独分包，仍有 >500kB 警告，保留可见警告。M0 不通过改阈值隐藏它，也不为此引入复杂加载框架。
- Browser 插件不可用，以临时 Playwright Core 1.64.1 + 系统 Chromium 验证；不把 M8 的端到端框架提前加入项目依赖。

## 完整版本 · 2026-10-26

- 用户最新明确要求全部完成并推送GitHub、部署Render，覆盖原计划的逐阶段停顿与未授权不得发布限制。连续推进M1～M9；不修改原始计划书。
- 保留Phaser + 纯TS权威仿真。战斗模块按当前规模拆为World、攻击工厂、几何、录制/管理器；不为了匹配目录蓝图制造空类。UI、输入、渲染、音频独立。
- 采用程序几何美术，不新增在线素材依赖。白色实心真人、青色轮廓编号分身、橙红圆/菱形/三角敌人。
- 为防止Phaser平滑帧delta掩盖长帧，适配层传入game.loop.rawDelta；累加器在250ms以上显式暂停。
- 射击者90tick锁定方向，24tick预警；下一次锁定计时从本次锁定时刻算起，避免误变为114tick周期。
- 触控验证使用Chromium CDP创建真实浏览器pointer事件与捕获，未使用伪造pointerdown冒充多点触控。仍不代表真实设备验证。
- e2e夹具仅在Vite专用e2e模式动态导入。生产构建不包含测试入口；调试面板仅DEV显示。无在线调试、无作弊入口。
- CI与Render为静态发布；现有Render站点按用户说明由GitHub推送触发，不私自创建付费服务或索取无关凭据。
