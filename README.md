# 时间追猎 · CHRONO HUNT

**试玩：https://echo-rush.onrender.com**（沿用原部署地址）

你唯一的敌人，是上一轮的你。瞄准、开火、撤离——你刚才做过的一切，会成为下一轮敌对分身的行动。六轮短回合，利用记忆、走位和掩体击败过去的自己。

## 怎么玩

每轮最多12秒：射击击破3个金色时间锚，并击破所有珊瑚色历史分身，然后进入出口光环保持片刻撤离。第1轮用来建立历史，第2轮开始遇到过去的自己。白色实心是现在的你，红色轮廓是过去；过去只重演原来的位置与攻击方向，不重新追踪。

成功撤离后查看真实轨迹与射线复盘，再手动进入下一轮。历史按各自实际长度循环，最多保留最近3段。击破过去会让它本轮停火，在途子弹依然危险；下一轮历史会重新出现。六轮全部撤离获胜；生命归零或倒计时耗尽失败。每轮开始恢复20HP并补充技能。

| 操作 | PC | 手机横屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准与开火 | 鼠标瞄准、按住左键（J备选） | 推右摇杆 |
| 相位冲刺 | Space | 冲刺按钮 |
| 抹除脉冲 | Q，每轮1次，清历史弹并伤害附近过去 | 脉冲按钮 |
| 暂停 / 继续 | Esc / 页面按钮 | 页面按钮 |

掩体挡住真人和子弹，需要换位寻找射线。冲刺短暂免伤；历史中的冲刺只重演路径。脉冲也会被过去重演，先考虑下一轮你会站在哪里。

微信 / QQ 内置浏览器竖屏打开时，点 **“横向适配并开始”**，再将手机横握；不依赖系统自动旋转或原生方向锁定。游戏中右上角可恢复自动布局。支持全屏的浏览器可点“尝试全屏横屏”，缺少或拒绝接口时会回退到页面横向适配。底部工具栏变化时按实际可见区域调整尺寸。

失焦、隐藏、未启用适配时的手机竖屏或超过250ms的长帧会暂停；回到横屏/可见后仍须显式继续。音量和减少特效可保存；存储失败也可玩。纯静态、无账号/后端/API密钥。

## 开发和验证

Node **24.19.0** / npm **11.9.0**，依赖精确锁定。

```sh
npm ci --include=dev
npm run dev -- --host 0.0.0.0
npm run typecheck
npm test
npm run build
npm run preview -- --host 0.0.0.0
npm run test:e2e
```

dev默认5173端口、preview默认4173，以实际输出为准；preview只供本地验收。手机同网段访问电脑局域网IP。Playwright默认用/usr/bin/chromium，其他机器可指定CHROMIUM_PATH，或先npx playwright install chromium。

37项核心/配置/存储测试覆盖：手动攻击、历史真实伤害、快照不变、无递归录制、不同记录长度循环、FIFO、墙体与高速碰撞、技能、容量、暂停、六轮胜败与重开。其中一个外部控制器只发送普通移动/瞄准/开火指令，在**不修改生命/任务/时间**的情况下打通六轮，击破12个过去与18个锚。

10个浏览器流程覆盖原生接口缺失/拒绝时的横向适配、旋转坐标下的双摇杆、工具栏高度变化、复盘期间方向切换，以及鼠标实弹击破时间锚、真实键鼠第一轮撤离、轨迹复盘、敌对分身、六轮状态流、20次重开与监听器计数、存储失败、双触点移动射击和方向切换。部分状态导航用专用e2e模式夹具；不把夹具导航写成真人完整通关。正式构建不包含__CHRONO_TEST__接口。

## 架构

- `src/core/World.ts`：纯TS实体、战斗、目标、回合、伤害与计时。
- `src/core/echo/`：只读快照与敌对事件重演；`clock/`固定步；`math/`碰撞几何。
- `src/adapters/`：统一键盘、世界坐标鼠标和双摇杆，以及原生全屏请求/微信横向适配和触控坐标转换。
- `src/view/`：原版程序几何、轨迹、插值与音效；`src/ui/`：菜单、HUD、复盘、设置。
- `docs/design-v2.md`：当前规则；`docs/plan.md`：历史旧版；`docs/qa.md`：实际证据与限制。

## Render Static Site

仓库main已连接原Render静态站点，推送自动构建；render.yaml定义同一工作流：

- 根目录留空，Node24.19.0。
- Build Command：`npm ci --include=dev && npm run typecheck && npm test && npm run build`
- Publish Directory：`dist`；无需Start Command或SPA重写。

仍需真实Android/iOS与Safari验证。Linux模拟触摸不代表真实多指硬件、音频策略或移动GPU帧率；Phaser分包约1.21MB，保留构建体积警告。当前按用户要求恢复2.0的简洁几何画面，移除实验室和装甲角色素材，保留微信/QQ横向适配。旧版十分钟测试不能代表本次新玩法，当前结果见qa.md。
